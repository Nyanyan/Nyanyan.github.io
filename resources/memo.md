# タイル一覧の編集

作品・展示のトップページでは、`HTML_TILE_BEGIN` と `HTML_TILE_END` で囲んだ箇条書きからタイルを生成します。

```markdown
HTML_TILE_BEGIN
- タイトル
  - ./hoge/
  - img/hoge.jpg
- タイトル2<br>説明
  - ./fuga/
  - img/fuga.jpg
HTML_TILE_END
```

1つのタイルは、字下げしないタイトルの箇条書きと、2つの子の箇条書きで指定します。子の箇条書きの先頭には半角スペースを2つ以上置き、リンク先、画像パスの順に書いてください。タイルは記載順に並びます。タイトルに `<br>` を書くと、その位置で表示が改行されます。

画像パスと相対リンクは、編集するページからの相対パスです。画像がそのページの `img` フォルダにある場合は `img/hoge.jpg` と書いてください。ブロック内の空行は無視され、同じページに複数のブロックを置くこともできます。

記法に不足や誤りがある場合は、HTML生成時に対象ファイルと行番号を表示して停止します。
