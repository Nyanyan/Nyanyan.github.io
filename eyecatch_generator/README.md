# アイキャッチ画像作成

`bin\Release\EyecatchGenerator.exe` を起動します。

1. 「画像を開く」でファイルを選ぶか、画像ファイルをウィンドウにドロップします。JPEG・PNG・WebP・BMP に対応しています。
2. 「アイキャッチ」か「正方形タイル」を選びます。サイトの制作メモ（`../img/working/README.txt`）に合わせて、アイキャッチは 1200×720 px、正方形タイルは 512×512 px が標準です。アイキャッチでは 1280×720 px と 1280×768 px、正方形タイルでは 256×256 px も選べます。
3. 枠の内側をドラッグして切り取り範囲を移動します。枠の角をドラッグするか、画像の上でマウスホイールを回すと、出力サイズの縦横比を保ったまま枠を拡大・縮小できます。画像内の枠外からドラッグすると、新しい範囲を選べます。「枠をリセット」で、画像の中央に収まる最大の枠に戻せます。
4. リボンを付ける場合は金・銀・銅・青から選びます。リボンは出力画像の左上に付きます。
5. プレビューを確認し、「名前をつけてJPEG保存」でファイル名と保存先を指定します。

## ビルド

Windows で Visual Studio 2022 の「C++ によるデスクトップ開発」と OpenSiv3D 0.6.16 をインストールします。`EyecatchGenerator.vcxproj` を開き、`Release | x64` でビルドします。

ビルド時に、Visual Studio のプロジェクトテンプレートにある `OpenSiv3D_0.6.16.zip` からエンジンのリソースを取り出します。テンプレートを別の場所に置いている場合は、MSBuild の `Siv3DTemplateZip` プロパティにその ZIP のパスを指定します。金・銀・銅・青の受賞リボンには、サイトの `../img/working/works/award/` にある PNG を使います。ビルドした実行ファイルにはエンジンのリソースと受賞リボンが入っています。
